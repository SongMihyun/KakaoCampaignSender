# v1.0.38 Beta Release Notes

- Ctrl+T 묶음 첨부 입력 전략을 전수 정리
- 기본 묶음 첨부 입력 모드를 `direct_paths_then_names`로 변경
- 파일 선택창이 열리면 파일 목록/썸네일 선택보다 절대 경로 직접 붙여넣기를 먼저 시도
- 절대 경로 직접 입력이 실패하면 기존의 발송 1회별 `batch_...` 폴더 이동 후 `a001.png`, `a002.png` 짧은 파일명 입력으로 fallback
- 짧은 파일명 입력도 실패할 때만 파일 목록 UI 선택 fallback 수행
- 기존 PC에 `navigate_then_names` 설정이 남아 있어도 새 직접 경로 우선 전략으로 자동 승격
- 파일 선택창 본체를 오류 팝업으로 오인하던 감지 조건 개선

## 기대 효과

- 파일 선택창에서 이미지 썸네일 목록을 읽느라 늦어지는 시간을 줄임
- PC별 파일 선택창 버전/포커스 차이에 따른 오류 가능성을 줄임
- 오류 팝업 처리 실패 후 목록 선택/업로드 단계가 꼬이는 흐름 완화
