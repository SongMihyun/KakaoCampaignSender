# v1.0.36 Beta Release Notes

- Ctrl+T 묶음 첨부용 임시 파일명을 발송 1회별 짧은 ASCII 파일명으로 변경
- `temp_attachments` 바로 아래에 파일을 누적하지 않고 `batch_...` 하위 폴더를 생성한 뒤 이번 발송 파일만 복사
- 파일 선택창 파일명 입력칸에는 `"a001.png" "a002.jpg"`처럼 짧은 이름만 입력
- 긴 `attach_YYYYMMDD_HHMMSS_001_hash.ext` 파일명 여러 개를 붙여넣을 때 일부 PC에서 파일명이 잘리거나 잘못 해석되는 문제 개선
- 파일명 직접 입력 실패 시에도 해당 batch 폴더에는 이번 발송 파일만 있어 기존 목록 선택 fallback 속도가 빨라지도록 개선
- 오래된 `batch_*` 임시 폴더 정리 로직 추가

## 개선 대상

- Windows 파일 선택창에서 `파일 이름이 올바르지 않습니다` 팝업이 발생하는 PC
- `temp_attachments` 폴더에 과거 첨부 이미지가 많이 쌓여 파일 선택/업로드가 느려지는 환경
- Ctrl+T 묶음 발송에서 파일 선택창은 열리지만 N개 전송 단계로 넘어가지 못하던 환경
