# v1.0.13 Beta Release Notes

## 사용자별 로컬 DB 분리

- 로그인 계정별로 로컬 DB를 분리합니다.
- 새 DB 경로는 `AppData/Local/kakao_campaign_sender/users/{user_uuid}/contacts.sqlite3`입니다.
- 기존 단일 DB(`contacts.sqlite3`)는 어떤 사용자에게도 자동 귀속하지 않습니다.

## 기존 단일 DB 보호

- 기존 단일 DB가 발견되면 `orphan_backups` 폴더에 백업만 생성합니다.
- 백업에는 `.meta.json` 파일이 함께 생성되어 원본 경로, 생성 시각, 해시, 사용 완료 여부를 기록합니다.
- 앱은 기존 단일 DB를 자동으로 새 계정 DB에 복사하지 않습니다.

## 수동 가져오기

- 설정 메뉴의 `기존 백업 데이터 가져오기`에서만 기존 백업을 현재 계정으로 가져올 수 있습니다.
- 가져오기 전 공용 PC 데이터일 수 있다는 경고를 표시합니다.
- 현재 계정 DB가 비어 있을 때만 가져오기를 허용합니다.
- 가져오기 성공 후 백업 파일은 `orphan_backups/claimed`로 이동되어 사용 완료 처리됩니다.

## 운영 기준

- 공용 PC와 개인 PC 모두 기존 DB 자동 이관은 금지됩니다.
- 공용 PC에서는 자동 알림 없이 사용자가 직접 가져오기 메뉴를 선택해야 합니다.
- 개인 PC에서도 사용자가 직접 확인해야만 가져올 수 있습니다.
